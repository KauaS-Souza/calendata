# 📅 Sprint - Consumo de API (Caldays API)

Uma aplicação web responsiva desenvolvida em **HTML, CSS e JavaScript** que consome dados da API pública Caldays para exibir informações sobre calendários e feriados de forma dinâmica e assíncrona.

## 🚀 Demonstração

- **Link do Deploy (Vercel):** [Clique aqui para acessar o projeto](SEU_LINK_DO_DEPLOY_AQUI)
- **Status do Projeto:** Concluído ✅

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da interface.
* **CSS3:** Estilização moderna, layout em Grid/Flexbox e responsividade.
* **JavaScript (ES6):** Manipulação do DOM e lógica de consumo da API.
* **Fetch API:** Requisições HTTP para comunicação com o servidor.
* **Caldays API:** Fonte de dados pública para listagem de informações de calendário.

---

## 📌 Funcionalidades

- **Consumo Assíncrono:** Uso de `async/await` para buscar dados na API sem travar a interface.
- **Renderização Dinâmica:** Os dados retornados são processados e exibidos na tela em formato de cards organizados.
- **Tratamento de Erros:** Caso ocorra falha de conexão ou resposta inválida da API, o usuário recebe uma mensagem informativa e amigável na tela.
- **Design Responsivo:** Interface adaptável para dispositivos móveis, tablets e computadores.

## 📂 Estrutura do Projeto

O projeto segue uma estrutura de pastas organizada e modular:

```text

├── src/
│   ├── assets/         # Imagens e mídias do projeto
│   ├── css/
│   │   └── global.css  # Estilização global e responsividade
│   ├── js/
│   │   └── script.js   # Consumo da API e manipulação do DOM
│   └── index.html      # Página principal da aplicação
└── README.md           # Documentação do projeto
```

## 💡 Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/KauaS-Souza/calendata.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd calendata
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador ou utilize a extensão **Live Server** no VS Code.
